## 💡 О проекте и образовательная ценность

«Питомец Финни» — интерактивная мобильная игра, где финансовая грамотность преподносится не через скучные тесты, а через **прямую заботу о виртуальном друге**. 

Игра создана в соответствии с **Единой рамкой компетенций по финансовой грамотности** (Минфин РФ / Банк России) и ориентирована на ключевой психологический принцип детей 7–11 лет: **«Обучение действием»** и **«Безопасная ошибка»**.

### 🌟 Ключевые педагогические принципы:
1. **«Сначала планируй — потом трать»:**  
   По ТЗ (п. 2.5.5) и разъяснениям жюри, план составляется *до* расходов. Приложение мягко блокирует импульсивные траты: если ребёнок нажимает на «Лавку», «Задания» или «Мечту» в начале дня, игра сначала открывает удобную шторку распределения бюджета. После закрепления плана нужный экран открывается автоматически!
2. **Безопасная ошибка (No Game Over):**  
   Финни не может заболеть, умереть или сбежать. Если денег не хватило или случился непредвиденный расход (протекла крыша в ливень) — игра объясняет причинно-следственную связь, предлагает заработать монеты на мини-работе или пересмотреть необязательные траты.
3. **Разделение потребностей, желаний и накоплений:**  
   Чёткая категоризация: **Обязательные траты** (еда, забота), **Необязательные радости** (игрушки, декор), **Финансовая подушка** (запас в кошельке) и **Мечта** (копилка на большую цель).

## 🎮 Игровые механики и возможности

### 🦊 1. Живой и отзывчивый питомец
- Векторный персонаж с плавной мимикой, морганием, реакциями на поглаживания и тапы (прыжки, танцы, радость, взмахи лапкой).
- **3 стадии взросления:** «Новичок» ➔ «Планировщик» ➔ «Самостоятельный» (меняются визуально по мере успешных решений за серию дней).
- **Гардероб и стиль:** 3 базовых окраса, надевание непромокаемого дождевика при ливне и кастомизация цвета куртки через встроенный Color Picker.

### 🏠 2. Инновационная 3-слойная сцена комнаты
- **Слой 1 (Окно и живая погода):** вид из окна динамически меняется в зависимости от прогноза на день (яркое солнце, облака, грозовой дождь, ветер, праздничные гирлянды).
- **Слой 2 (Постоянный интерьер):** векторная комната с прорезанным окном (`evenodd` path), остающаяся уютной в любую погоду.
- **Слой 3 (AI-иллюстрации купленных вещей):** купленные предметы (уютная лежанка, лампа, мяч, робот, воздушный змей) появляются в комнате с прозрачным фоном и реагируют на тапы ребёнка.

### 🪙 3. Сбалансированная игровая экономика
- **Стартовый капитал:** 50 игровых монет при начале игры.
- **Ежедневный доход:** 3 🪙 утренней поддержки от семьи.
- **Интерактивные мини-игры (заработок):** «Расставь ценники» и «Собери заказ» приносят честные 10 монет в день за внимательность.
- **7 финансовых миссий по 3 ключевым темам:**
  1. *Планирование бюджета:* «Три конверта».
  2. *Сравнение цен и покупки:* «Корзина на три дня», «Проверь сдачу».
  3. *Накопления и сбережения:* «Дорожка к мечте», «Что оставить на завтра?», «План Б для крыши», «Перед ярмаркой».
- **Финансовые цели («Мечта»):** Скейт (80 🪙), Домик на дереве (100 🪙), Ракета (125 🪙) с возможностью пополнения, частичного снятия и фиксацией победы.
- **Вечерние итоги дня:** Наглядный экран сопоставления «План vs Факт» без негативных оценок.

### 🎵 4. Атмосферное аудио и звуковое оформление
- Зацикленная, ненавязчивая эмбиент-музыка для погружения в атмосферу.
- 5 сочных звуковых эффектов (звон монет, тап, фанфары победы, предупреждение, чириканье Финни).
- **Умный жизненный цикл:** музыка автоматически глушится при сворачивании приложения (Home, свайп, блокировка) и плавно восстанавливается при возвращении. Отдельные ползунки громкости и тумблеры звука в настройках.

### 👨‍👩‍👧 5. Раздел для родителей
- Защищён математическим барьером от случайного входа ребёнком.
- Описание развиваемых компетенций и тем.
- Функция безопасного сброса игрового прогресса для повторного прохождения.

## 🛠️ Архитектура и стек технологий

```
lib/
├── core/                  # Базовые сервисы и дизайн-система
│   ├── sound/             # SoundService: BGM, SFX, Lifecycle, AudioContext
│   └── theme/             # Токены FinnyColors, типографика, адаптивные стили
├── data/                  # Модели данных и локальное хранилище
│   ├── models/            # GameState, Profile, BudgetPlan, Inventory
│   └── repositories/      # GameRepository (SharedPreferences, DemoProfile)
├── game/                  # Игровая логика и образовательный контент
│   ├── content/           # 7 финансовых заданий, 10 товаров, дни 1-10
│   └── engine/            # GameEngine (StateNotifier, транзакции, фазы дня)
├── features/              # UI-модули приложения
│   ├── home/              # Главный экран, 3-слойная комната, карточки дня
│   ├── planning/          # Шторка планирования бюджета (4 конверта)
│   ├── shop/              # Лавка товаров с проверкой средств
│   ├── goals/             # Копилка и выбор цели
│   ├── work/              # Мини-игры заработка (Ценники, Сбор заказа)
│   ├── progress/          # Дневник, словарь терминов, список заданий
│   ├── adult/             # Защищённый раздел для родителей
│   └── demo/              # Панель демонстрационного режима для жюри
└── shared/widgets/        # Общие компоненты (PetAvatarWidget, RoomSceneSvg)
```

- **Фреймворк:** Flutter 3.x (Dart 3.x)
- **Управление состоянием:** `flutter_riverpod` (архитектура без утечек состояния)
- **Хранилище данных:** `shared_preferences` (JSON-сериализация, 2 независимых слота: обычный и демо)
- **Векторная графика:** `flutter_svg` с изоляцией растровых слоев
- **Аудио-движок:** `audioplayers` 6.8 с оптимизированным бесконфликтным аудиофокусом

## 📦 Сборка и запуск из исходников

Для сборки проекта требуются **Flutter SDK (3.24+)** и **Android SDK (API 34+)**:

```bash
# 1. Клонировать репозиторий
git clone https://github.com/TABURELTER/Finny-android-app.git
cd Finny-android-app

# 2. Получить зависимости
flutter pub get

# 3. Проверить статическим анализатором (0 ошибок, 0 предупреждений)
flutter analyze

# 4. Собрать подписанный релизный APK
flutter build apk --release
```

Готовый файл сборки появится по пути:  
`build/app/outputs/flutter-apk/app-release.apk` (также скопирован в корень как `finny-pet-release.apk`).
